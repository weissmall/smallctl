# AGENTS.md

Guide for AI coding agents working in this repository.

- Follow the commit conventions in [docs/CONTRIBUTING.md](docs/CONTRIBUTING.md)
  for every commit you make: Conventional Commits (`feat:`, `fix:`, `docs:`,
  ...), short but descriptive subjects, no attribution lines.
- Before committing, inspect `git status` and `git diff`; stage only intended
  files.
- Run `go test ./...` and `go vet ./...` before finishing a code change.
